# Code, Explained. visual specification

The accepted visual direction is a focused learning workspace rather than a
marketing page.

## Design tokens

- Page background: true white `#ffffff`
- Primary text: ink navy `#071330`
- Muted text: slate `#52617a`
- Primary action: electric blue `#074bf6`
- Selected explanation: pale sky `#edf5ff`
- Selected code: warm yellow `#fff1b8`
- Error: coral `#d94841`
- Borders: cool gray `#dfe5ee`
- Headings and controls: rounded geometric system sans
- Code: crisp system monospace
- Radius: 9–12px, with nearly flat shadows

## Layout

- Quiet text-only brand header.
- Compact headline and one supporting sentence.
- Two-column desktop workspace with the editor on the left and the explanation
  rail on the right.
- One short whole-program summary at the top of the explanation side.
- Open vertical lesson rail below the summary.
- Selected explanation and selected code lines share accent colors.
- Mobile order is code first, explanation second.

## Copy lock

- `Code, Explained.`
- `Paste C++. Get the story.`
- `Every one or two lines, explained in one clear sentence.`
- `Your C++ code`
- `Explain my code`
- `The simple version`
- `Your code is explained, not run.`

There are no marketing sections, badges, fake metrics, predicted-output
sections, or possible-problem sections.
